# The AnyDag guide

How to use AnyDag, one topic per page. Start with **Getting started**, then go to whichever topic you
need.

| Page | Covers |
|---|---|
| [Getting started](getting-started.md) | installing the app, opening your first folder, finding your way around, search, keyboard shortcuts |
| [Notes](notes.md) | writing, linking notes with `[[wikilinks]]`, equations, pictures and files, backlinks, exporting a PDF |
| [Boards and diagrams](boards.md) | the infinite canvas: mind maps, timelines, flowcharts, charts, sketches, and the fourteen diagram types |
| [Quizzes](quizzes.md) | making a quiz from your notes, practising, and the Mistakes run |
| [Tables](tables.md) | reading lists, trackers and small databases: typed columns, sorting, filtering, CSV |
| [Tasks, projects and the calendar](tasks-and-calendar.md) | to-dos with due dates, projects, events, and the calendar that shows them |
| [AI and agents](ai.md) | the Assistant, prompt cards, and letting an AI agent work in your folder |
| [Your files, sync and privacy](files-and-sync.md) | what is on your disk, the trash, the read-only lock, end-to-end encrypted sync, anonymous logs |

These pages are for people using the app. If you want to change its code, read
[`CONTRIBUTING.md`](../../CONTRIBUTING.md) and the architecture notes in
[`docs/architecture/`](../architecture/README.md) instead.
