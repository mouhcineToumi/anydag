    person learner "Learner" "Studies for a cloud certification."

    system larkspur "Larkspur" "software system" hue=indigo {
      container api "API" "FastAPI · Python 3.12" "Serves content, profiles and progress."
      db store "Database" "Firestore" "Holds tracks, nodes, profiles and progress."
    }

    extsystem auth "Firebase Auth" "Signs learners in and issues the id tokens."

    learner --> web "Uses" "HTTPS"
    api --> auth "Verifies id tokens with" "Admin SDK"

Three strings for a `container` / `db` (name, technology, description); **two** for a `person` or
`extsystem` (name, description). The description is the only text in the system that wraps, which
is why C4 boards are tall. An edge's second string is its technology chip.
